# Victor Buitoni - Portfólio

Portfólio pessoal de Engenharia de Dados, Business Intelligence e Machine Learning.

## Acessar

O site pode ser publicado gratuitamente com GitHub Pages:

1. Abra **Settings** no repositório.
2. Acesse **Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Escolha a branch `main` e a pasta `/ (root)`.
5. Aguarde a publicação.

## Desenvolvimento local

Abra `index.html` diretamente no navegador ou execute um servidor local:

```bash
python -m http.server 8000
```

Depois acesse `http://localhost:8000`.
